# Fonts

Downloaded automatically at runtime by `main.py` (`ensure_fonts()`) from the
[google/fonts](https://github.com/google/fonts) repository:

- **Anton** — English captions (SIL Open Font License 1.1)
- **Mukta Malar Bold** — Tamil captions; covers both Tamil and Latin scripts
  (SIL Open Font License 1.1)
